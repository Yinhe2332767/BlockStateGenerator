# BlockStateGenerator
Simple python script to generate blockState file for registering 6-facing-4-norm-type of blocks in a minecraft mod. 

It's a really simple script. Config stuff on top of the file, hit run and it'll generate a json & print check if your choosen configurations can cover all 24 orientations.  
Requires numpy. 

It's so simple I didn't bother benchmarking. Sorry for publishing the same thing if you have already done so.
